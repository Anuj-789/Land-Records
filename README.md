# 📖 About the Project

This is a **personal utility project** that I created to save time while checking my family's land records on the **Bihar Bhumi** portal.

Earlier, whenever I needed to check a land record, I had to visit the Bihar Bhumi website, select the district, circle, village, khata, plot number, and fill in the same information repeatedly.

Since I frequently access the same land records, I built this project to simplify the process.

Now, I only need to:

* Select the village.
* Select the land owner's name.
* Click the **Search** button.

The application immediately opens the corresponding land record from the official Bihar Government portal in a new tab, eliminating repetitive manual steps. This project simply provides quick navigation to records that are already available on the official government portals.
